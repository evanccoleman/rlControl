DATE: Spring 2026

==================================

OVERVIEW:

Get proper packages...
pip list --format=freeze > requirements.txt
pip install -r requirements.txt

What is implemented...
- Various Stable-Baselines3 agents
- Gymnasium environments
- POMDPWrapper class
- CustomDDPG and FrameDDPG agents

Note:
- files from the cluster may have a 1-hour time difference

==================================

GOAL:

1. Does memory (LSTM) improve agent performance in continuous
control environments?

2. Does memory (LSTM) improve agent performance in POMDPs?

==================================

SUMMARY OF PROJECT DIRECTORIES:

Factories:
agents/ --> factory to create, save, and load agents
envs/ --> factory to create envs, POMDP wrapper

Inputs/Outputs:
param_files/ --> stores hyperparameters to try to train new agents on
outputs/ --> eval callbacks, info on runs, and saved agents from training
             graphs from graphing
find_best_agent/ --> script that looks at multiple saves of the same agent
             from a single run and determines which save is the best

Training:
training/ --> run the walkers_v5.py training script

Tuning:
tuning/ --> run the optimizer.py hyperparameter tuning script

Graphing:
graphing/ --> run graphit.py to graph agent results

Miscellaneous:
old/ --> old agents, walker files, optimizer, graph scripts from Aug 2025 
notes/ --> personal notes
